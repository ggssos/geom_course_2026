# ДЗ №6. Исследование результатов расчёта в ParaView

В ДЗ №4 вы строили тепловые карты и изолинии, а в ДЗ №5 — анимацию и интерактивный график. Теперь эти способы представления нужно применить к результатам двумерного расчёта осадочного бассейна в ParaView.

Задание разделено на три последовательные части:

| Часть | Что сделать | Результат |
| --- | --- | --- |
| [6.1. Установка](6.1_installation.md) | Установить ParaView и открыть тестовую сетку | Скриншот и версия программы |
| [6.2. Обзор](6.2_overview.md) | Разобраться с интерфейсом, сеткой, полями и цепочкой фильтров | Ответы на вопросы и мини-упражнение |
| [6.3. Практика](6.3_assignment.md) | Конвертировать данные, исследовать маску и поля, построить профиль и анимацию | Состояние ParaView, изображения, CSV и анимация |

Читайте части по порядку. Для конвертации в 6.3 используется готовая Windows-программа **BasinToVTK.exe** с одной кнопкой. Python и библиотеки для неё устанавливать не требуется.

## С какими данными работаем

В [data/result.h5](data/result.h5) находится готовый результат бассейнового теплового солвера: температура, пористость и литология для 18 геологических эпох. **Запускать солвер и знать уравнение теплопроводности для выполнения задания не требуется.** Здесь нужно корректно прочитать и представить уже рассчитанные данные.

В ДЗ №4–5 областью была полная прямоугольная сетка. Здесь на той же прямоугольной сетке часть ячеек не принадлежит породам. Массив `active` указывает, какие ячейки входят в область в выбранную эпоху. Маска меняется со временем.

Это двумерный разрез, а не объёмный расчёт. Его координаты в ParaView: X — горизонтальная координата, Y — минус вертикальная координата модели, Z — ноль. Поэтому породы отображаются ниже нулевой отметки. Все координаты заданы в метрах.

Подробное описание данных и их происхождения: [data/README.md](data/README.md).

## Перед началом

Обновите **свой fork**: на GitHub откройте его главную страницу, нажмите **Sync fork → Update branch**. Если GitHub сообщает о конфликте, сохраните свои изменения и обратитесь к преподавателю. Не используйте принудительную перезапись своей ветки.

Затем в терминале VS Code откройте корень своей локальной копии курса — папку, в которой видны `README.md`, `homeworks` и `.git`. Убедитесь, что свои изменения сохранены в коммите, и выполните:

```powershell
git status
git pull
```

Если появилась ошибка `not a git repository`, сначала перейдите в папку клонированного репозитория командой `cd`. Команды ниже выполняются **из корня репозитория**, а не из `homeworks/hw06`.
