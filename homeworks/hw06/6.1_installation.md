# 6.1. Установка ParaView и первый запуск

Цель этой части — получить работающую программу и открыть маленькую тестовую сетку. Её можно выполнить до занятия. Основная инструкция рассчитана на Windows 10/11, 64 бита.

## 1. Скачайте программу

1. Откройте [официальную страницу загрузки ParaView](https://www.paraview.org/download/).
2. Выберите стабильный выпуск ParaView для своей системы. Инструкция ориентирована на ветку **6.x**; номер установленной версии запишите в `answers.md`. Не выбирайте Nightly или Release Candidate (RC).
3. Для обычного ноутбука с Windows и процессором Intel/AMD выберите **Windows, AMD64/x86_64**, сборку **без MPI**. AMD64 означает 64-битную архитектуру и подходит также для Intel. Если у вас Windows на ARM, сначала уточните совместимую сборку.
4. Выберите установщик `.msi`/`.exe` либо переносимый архив `.zip`, если он предлагается. Не скачивайте Source Code: это исходный код для сборки программы.

`MPI` относится к параллельным вычислениям на нескольких процессах. Для нашего задания отдельная MPI-сборка не требуется. Слово `Python` в названии дистрибутива обозначает встроенные средства ParaView; ваш Python курса устанавливается и используется отдельно.

## 2. Установите или распакуйте

**Вариант с установщиком:** откройте скачанный файл, пройдите шаги мастера установки и запустите ParaView через меню «Пуск».

**Вариант с ZIP:** щёлкните архив правой кнопкой → «Извлечь всё». Распакуйте, например, в `C:\Tools\ParaView`. Откройте распакованную папку, затем `bin` и запустите `paraview.exe`. Не запускайте программу прямо из архива и не переносите один EXE отдельно от остальных файлов.

При первом запуске можно закрыть приветственное окно. На macOS используется официальный установщик для архитектуры Mac; на Linux — официальный готовый архив и исполняемый файл `bin/paraview`. Дальнейшая работа с данными одинакова.

## 3. Найдите основные панели

В окне нужны:

- **Pipeline Browser** — список источников и фильтров;
- **Properties** — настройки выбранного объекта и кнопка **Apply**;
- **Render View** — область изображения;
- элементы управления временем — понадобятся в 6.3.

Если первые две панели скрыты, включите их через меню **View**. Расположение панелей и подписи отдельных кнопок могут немного различаться между версиями.

Откройте **Help → About ParaView** и запишите номер версии.

## 4. Откройте тестовую сетку

Файл уже находится в обновлённом репозитории:

```text
homeworks/hw06/data/installation_test.vti
```

1. Выберите **File → Open**.
2. Найдите этот файл на своём компьютере и откройте его.
3. Нажмите **Apply** в панели Properties.
4. В Pipeline Browser выберите `installation_test.vti`.
5. В списке **Representation** выберите **Surface With Edges**.
6. В списке раскраски, где может стоять `Solid Color`, выберите `temperature_C`.
7. Нажмите **Reset Camera**, чтобы сетка целиком попала в кадр.
8. Выберите вид вдоль Z — кнопка **+Z** или **−Z** на панели камеры. Видна плоскость XY; одна из этих кнопок показывает её с противоположной стороны. Для обычного положения X вправо и Y вверх используйте вид со стороны +Z.
9. Покажите цветовую легенду кнопкой **Show Color Legend**; при необходимости найдите её по всплывающей подсказке.

Вы должны увидеть прямоугольник из **трёх столбцов и двух строк**, всего шесть ячеек. Диапазон `temperature_C` — **10–60**. Пока отображаются все шесть ячеек, в том числе одна с `active = 0`: маску применим в части 6.2.

Сделайте скриншот **окна программы**: должны быть видны сетка, Pipeline Browser и Properties. Сохраните в:

```text
homeworks/hw06/screenshots/installation.png
```

## 5. Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Ошибка про `msmpi.dll` | Вероятно, скачана MPI-сборка. Используйте обычную сборку без MPI. |
| Окно пустое после открытия файла | Нажмите Apply, включите значок глаза у источника и выполните Reset Camera. |
| Видна только линия | Плоскость видна с ребра. Выберите вид со стороны +Z. |
| В раскраске нет температуры | Выберите источник тестовой сетки в Pipeline Browser и проверьте, что открыт файл `.vti`. |
| Нет панели Properties | Включите её в View и выберите объект в Pipeline Browser. |
| Не найден `installation_test.vti` | Обновите fork, выполните git pull и проверьте путь в своей локальной копии курса. |

Не скачивайте отдельные DLL с посторонних сайтов. Если программа не запускается, запишите версию ОС, название скачанного дистрибутива и полный текст ошибки для разбора на паре.
