ДЗ №6.2 Обзор ParaView

1. Какие данные задают сетку, а какие — значения температуры на ней?
Сетка задаётся координатами точек и раположением ячеек из installation_test.vti. 
Значения температуры хранятся отдельно в temperature_C

2. Чем Cell Data отличается от Point Data?
Cell Data хранит значения для каждой ячейки, а Point Data — для каждой точки сетки

3. Почему после Threshold на тестовой сетке остались пять ячеек? Исчезла ли шестая ячейка из исходного файла?
Пять ячеек имеют значение active = 1, а шестая — active = 0, поэтому она не прошла фильтр. 
Из исходного файла она не исчезла

4. Что произойдёт, если добавить Contour к исходной серии, минуя маску?
Изолинии построятся как по активным, так и по неактивным ячейкам, которые не входят в 
активную область

5. Почему код литологии нельзя усреднять так же, как температуру?
Потому что каждой породе соответствует определённый код, их усреднение не имеет 
никакого смысла

6. Почему для сравнения эпох нужен фиксированный диапазон цветов?
Чтобы одинаковые цвета обозначали одинаковую температуру на разных эпохах

7. Какому геологическому возрасту соответствует время ParaView 185?
15 миллионов лет

8. Почему появление плавных изолиний не означает, что исходная сетка стала мельче?
Потому что линии выглядят гладкими только на изображении, а сама сетка не меняется


ДЗ №6.3 Визуализация геологической истории

1. Сколько ячеек в полной сетке и сколько осталось после Threshold в возрастах 200, 75 и 0 Ma? 
Сравните с таблицей в задании.
В полной сетке 5152 ячейки. После Threshold: 200 - 794, 75 - 3441, 0 - 4821

2. Почему NaN вне области нельзя заменить нулевой температурой?
Потому что NaN означает отсутствие значения температуры, а не 0

3. Почему Contour строится после маски и после преобразования температуры в Point Data?
После маски Contour строит линии только внутри области пород, Point Data нужен, чтобы перевести
температуру из ячеек в точки для удобства Contour

4. Какие три пары z–T получились из CSV для x = 750 м? Как исключены недопустимые точки?
Для X = 750 м получены, например, три пары z–T: (540; 17,142), (600; 17,982), (830; 26,77). 
Недопустимые точки исключались с помощью vtkValidPointMask: учитывались только строки со значением 1.

5. Какой код литологии выбран вторым Threshold? Что видно при смене эпох?
Во втором Threshold выбран код литологии 1003. С течением времени эта порода появляется в бассейне, 
постепенно распространяется, а затем её количество немного уменьшается. 
При этом меняется и её расположение по глубине.

6. Что означает пористость 0,25 и как она подписана на вашей легенде?
Пористость 0,25 означает, что поры занимают 25% объёма породы. На легенде она отображается как porosity_fraction

7. В каких единицах время на анимации? Как вычислить геологический возраст из показанного числа? 
Сохранены ли реальные соотношения длительностей интервалов?
Время указано в миллионах лет (Ma). Геологический возраст можно вычислить как 200 минус показанное время.
Реальные соотношения длительностей интервалов не сохранены, так как только кадры показывают последовательность состояний

8. Какие файлы нужно иметь рядом с .pvsm, чтобы преподаватель открыл работу? Проверили ли вы повторное открытие?
basin.vti.series и файлы .vti, которые содержат данные для каждого временного состояния. Повторное открытие
проверила
