## 2. Создайте учебное поле

Изменение временного ряда относительно первого момента:

```python
time_component = well_pressure_mpa - well_pressure_mpa[0]
```

Изменение между наблюдательными скважинами относительно первой:

```python
radius_component = (
    observation_pressure_mpa
    - observation_pressure_mpa[0]
)
```

Создайте двумерный массив через broadcasting:

```python
pressure_field = (
    well_pressure_mpa[0]
    + time_component[:, np.newaxis]
    + radius_component[np.newaxis, :]
)
```

Проверьте:

```python
assert pressure_field.shape == (13, 7)
```

Строки массива соответствуют 13 моментам времени, столбцы — семи расстояниям.

## 3. Разберитесь с ориентацией массива

Для функций построения по горизонтальной оси будет находиться время, по вертикальной — расстояние.

Matplotlib ожидает, что:

- столбцы изображаемого массива соответствуют X;
- строки соответствуют Y.

Поэтому при построении используйте:

```python
field_for_plot = pressure_field.T
assert field_for_plot.shape == (7, 13)
```

Транспонирование здесь не меняет значения. Оно только согласует ориентацию массива с выбранными осями.

## 7. Добавьте изолинии

Поверх `contourf` постройте:

```python
lines = ax.contour(
    time_h,
    radius_m,
    field_for_plot,
    levels=levels,
    colors="black",
    linewidths=0.6,
)
```

Подпишите линии:

```python
ax.clabel(lines, fmt="%.2f")
```

Изолиния соединяет положения, в которых отображаемая величина имеет одинаковое значение.

Контуры могут выглядеть гладкими даже при редкой сетке, потому что их положение вычисляется интерполяцией между узлами. Это не означает, что программа получила новые измерения.

## Что важно понять

### Тепловая карта

- показывает значения на ячейках исходной сетки;
- позволяет увидеть размер и расположение ячеек;
- не требует выбора уровней;
- вид изображения зависит от разрешения сетки.

### Заливка по уровням

- объединяет значения в заданные интервалы;
- требует выбора количества и положения уровней;
- границы областей вычисляются между узлами сетки;
- может выглядеть более гладкой, чем исходные данные.

### Изолинии

- соединяют положения с одинаковым значением;
- позволяют читать конкретные уровни;
- не показывают все значения внутри областей;
- слишком большое число линий делает рисунок нечитаемым.
