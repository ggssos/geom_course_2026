# 6.3. Исследование тепловой истории бассейна

Вы получили результаты расчёта температуры двумерного разреза бассейна за 200 млн лет. Нужно показать изменение активной области и температуры, построить температурные изолинии и вертикальный профиль, сравнить два поля и сохранить анимацию.

Здесь продолжается работа с картами, изолиниями и анимацией из ДЗ №4–5. Источник данных новый: готовый расчёт солвера. Все необходимые поля включены в репозиторий. Расчёт запускать не нужно.

Операции выполняйте по порядку. Карту температуры, изолинии, профиль и литологию создавайте отдельными ветками одного Pipeline, чтобы их можно было включать независимо.

## 1. Получите временную серию VTK

Откройте в Проводнике папку своей копии курса, затем `homeworks/hw06/tools`.

1. Дважды щёлкните **`BasinToVTK.exe`**.
2. В окне есть одна кнопка: **«Выбрать файл для конвертации»**. Нажмите её.
3. Выберите **`homeworks/hw06/data/result.h5`** в своей локальной копии курса.
4. Дождитесь надписи **«Готово: 18 кадров»**.
5. Программа покажет папку результата: **`homeworks/hw06/data/result_vtk`**. Она создаётся автоматически рядом с исходным HDF5.

Устанавливать Python, библиотеки и выбирать папку сохранения не нужно. Программа рассчитана на Windows x64. На macOS/Linux используйте готовый архив серии из `tools/basin_vtk.zip`: распакуйте его в `homeworks/hw06/data/result_vtk`.

Если конвертировать тот же файл повторно, программа создаст новую папку с суффиксом `_2`, `_3` и так далее. Предыдущие результаты сохраняются. Для занятия удобнее использовать первую папку `result_vtk`; смотрите точный путь в окне программы.

В папке результата появятся:

- `basin_000.vti` — первая эпоха;
- ...;
- `basin_017.vti` — последняя эпоха;
- `basin.vti.series` — список файлов и их времён;
- `export_summary.json` — размеры сетки, диапазоны полей и число активных ячеек по эпохам.

Конвертер работает с завершёнными результатами формата `basin-thermal-history`, версия схемы 1, с равномерной прямоугольной сеткой. Произвольный HDF5 другой программы не подойдёт. Значения полей не интерполируются при экспорте. Координаты переводятся в вид X = x, Y = −z, Z = 0; порядок строк разворачивается, чтобы изображение не перевернулось.

## 2. Откройте все эпохи

1. В ParaView выберите **File → Open**.
2. Откройте **`basin.vti.series`**, затем нажмите Apply. Если файл не виден, выберите фильтр All Files.
3. Проверьте наличие 18 временных состояний в Time Manager или элементах управления временем. Если интерфейс показывает индекс, он идёт от 0 до 17.
4. Выберите Surface With Edges, `temperature_C`, вид со стороны +Z и Reset Camera. Разрез должен находиться в плоскости XY, глубина — идти вниз по экрану. При необходимости включите 2D interaction mode и настройте камеру с направлением вверх по +Y.

Если открыли только `basin_000.vti`, временной серии из 18 состояний не будет. Переоткройте именно `.vti.series`. Альтернативный вариант — открыть сгруппированные `basin_*.vti`, но тогда проверьте, что реальные значения времени не заменились индексами 0–17.

В **SpreadSheet View** выберите Cell Data. Найдите:

| Массив | Смысл |
| --- | --- |
| `temperature_C` | Температура, °C |
| `reflectance_percent` | Рассчитанная отражательная способность, %; в обязательной части не используется |
| `porosity_fraction` | Пористость, доля единицы |
| `lithology_code` | Целочисленный код литотипа |
| `active` | Маска: 1 — породы, 0 — вне активной области |
| `depth_m` | Исходная вертикальная координата z, м |

Поле `depth_m` — абсолютная вертикальная координата модели. Это **не расстояние под текущей поверхностью**: поверхность со временем меняется.

## 3. Выделите активную область

1. Выберите исходную серию.
2. Ctrl+Space → **Threshold**.
3. Выберите **Cell Data → active**.
4. Задайте метод **Between**, нижний и верхний пороги **1**.
5. Нажмите Apply. Переименуйте результат в `ActiveBasin` через контекстное меню Pipeline Browser.
6. Скройте исходный источник значком глаза и покажите `ActiveBasin`.

Откройте Information для результата фильтра и переключите эпохи:

| Время ParaView | Возраст | Число активных ячеек |
| ---: | ---: | ---: |
| 0 | 200 Ma | 794 |
| 125 | 75 Ma | 3441 |
| 200 | 0 Ma | 4821 |

Полная сетка всегда имеет 5152 ячейки. После Threshold их меньше и количество меняется. Убедитесь, что в Spreadsheet View результата `active` везде равен 1.

Не заменяйте отсутствующие температуры нулями. Ноль градусов — допустимое физическое значение, а не обозначение отсутствия пород. Одного NaN также недостаточно, чтобы явно задать геометрию активной области: для этого используем маску.

## 4. Покажите температуру в двух эпохах

1. Выберите `ActiveBasin` и раскраску **Cell Data → temperature_C**.
2. Используйте **Surface**, чтобы видеть карту без линий сетки.
3. Откройте редактор цветовой карты: **Edit Color Map**.
4. Выберите последовательную карту, например Viridis.
5. Установите **Rescale to Custom Range: 17–170** и отключите автоматическое изменение диапазона. Числа на легенде должны сохраняться при переключении эпох.
6. Включите легенду, подпишите её `Temperature, °C`. Допустима русская подпись `Температура, °C`.
7. Покажите координатные оси или **Axes Grid** с подписями `X, m` и `Y = -z, m`. Не называйте отрицательную Y положительной глубиной.
8. Настройте камеру на **весь** разрез в последнюю эпоху. Затем сохраняйте этот ракурс, масштаб и размеры окна во всех кадрах. Не нажимайте Reset Camera для каждой эпохи отдельно.

Через **File → Save Screenshot** сохраните карты размером не менее 1280 × 720:

```text
screenshots/temperature_200_ma.png    # время ParaView 0
screenshots/temperature_0_ma.png      # время ParaView 200
```

На каждом изображении должны быть видны активная область, легенда с единицами и подпись возраста. Для статической картинки можно добавить источник **Text**, например `Age: 200 Ma`. Перед сохранением следующей картинки обязательно измените подпись. Рамка всей сетки может быть показана отдельно, но не должна закрывать карту.

В `answers.md` напишите, как изменение геометрии и цвета различается на этих изображениях. Достаточно описания наблюдаемой картины, без физического объяснения причин.

## 5. Постройте температурные изолинии

Вернитесь к современной эпохе: **время ParaView = 200**, возраст = 0 Ma.

1. Выделите `ActiveBasin`.
2. Добавьте **Cell Data to Point Data**.
3. Отключите **Process All Arrays** и в списке **Cell Data Arrays** оставьте **только `temperature_C`**. Если настройки скрыты, включите расширенные свойства кнопкой с шестерёнкой.
4. Нажмите Apply, переименуйте результат в `TemperaturePoints`.
5. Выделите `TemperaturePoints`, добавьте **Contour**.
6. В Contour By выберите `temperature_C` и задайте уровни **50, 75, 100, 125, 150**. Удалите автоматически предложенные уровни, если они отличаются.
7. Покажите линии поверх исходной цветной карты `ActiveBasin`. Увеличьте Line Width, выберите контрастный цвет. Видимость `TemperaturePoints` можно выключить: он нужен как вход фильтра.

Не применяйте усреднение ко всему набору массивов: маска и литология имеют другой смысл. В подписи рисунка перечислите температурные уровни. Сохраните:

```text
screenshots/temperature_contours_0_ma.png
```

Сравните эту картинку с изолиниями Matplotlib из ДЗ №4: линия связывает точки одного значения, но теперь она строится только внутри области пород. Наличие гладкой линии не означает, что между ячейками появились новые расчётные данные.

## 6. Постройте вертикальный профиль температуры

Нужно получить график **температуры от вертикальной координаты z** при **x = 750 м** в современной эпохе.

Сначала создайте точную координату глубины в Point Data:

1. Выберите `TemperaturePoints`.
2. Добавьте **Calculator**.
3. Attribute Type: **Point Data**. Result Array Name: **`profile_depth_m`**.
4. Выражение: **`-coordsY`**. Здесь `coordsY` — Y-координата узла, а Y = −z, поэтому минус возвращает z.
5. Нажмите Apply. Переименуйте результат в `TemperatureWithDepth`.

Теперь профиль:

1. Выберите `TemperatureWithDepth` → **Plot Over Line**.
2. Point1: **(750, −450, 0)**.
3. Point2: **(750, −4450, 0)**.
4. Если доступны выбор режима отбора и Resolution, выберите равномерное семплирование (**Sample Uniformly**) и задайте Resolution = **400**. Иначе используйте доступный отбор по ячейкам и укажите его в ответе.
5. Нажмите Apply. Откроется график в **Line Chart View**. Если он не появился, разделите окно, выберите Line Chart View и включите в нём результат Plot Over Line.
6. В свойствах отображения графика отключите **Use Index For X Axis**, выберите X Array Name: **`profile_depth_m`**.
7. В списке Series оставьте только **`temperature_C`**.
8. Подпишите оси: X — `Вертикальная координата z, м`, Y — `Температура, °C`. В заголовке укажите x = 750 м и возраст 0 Ma.

Отрезок специально выходит за пределы пород. Для таких точек нет результата; в таблице появляется **`vtkValidPointMask`**: 1 — данные получены, 0 — точка вне области. Нулевые или пустые значения в строках с маской 0 нельзя трактовать как реальную температуру или соединять ими профиль. При необходимости выделите допустимые точки дополнительным Threshold по `vtkValidPointMask = 1` или исключите недопустимые строки перед анализом CSV. При пороге по Point Data метод отбора ячеек может затронуть соседние сегменты, поэтому сверяйте границы по исходной маске.

Сохраните график и **данные выбранного Plot Over Line**:

```text
screenshots/temperature_profile_0_ma.png
temperature_profile_0_ma.csv
```

Для CSV выберите Plot Over Line в Pipeline Browser → **File → Save Data → CSV**. Экспортируйте текущую эпоху, Point Data; не включайте запись всех времён. В CSV должны остаться `temperature_C`, `profile_depth_m` и `vtkValidPointMask` (некоторые версии добавляют координаты и `arc_length`).

Откройте CSV через Pandas, выберите строки с `vtkValidPointMask == 1` и приведите в `answers.md` **три пары z–T** из разных частей профиля. Значения должны соответствовать графику. Нельзя заменить профиль списком вручную переписанных чисел.

## 7. Покажите литологию

Создайте отдельную ветку от `ActiveBasin`, без преобразования кодов в Point Data.

1. В современной эпохе выберите **Cell Data → lithology_code**.
2. В редакторе карты включите **Interpret Values As Categories**. Вкладка может называться **Annotations** или **Indexed Colors**.
3. Создайте отдельные категории: **1001, 1002, 1003, 1004, 1005**. Подписи: `Литотип 1001`, ..., `Литотип 1005`. Можно использовать английское `Lithotype`, если шрифт программы не отображает кириллицу.
4. Убедитесь, что легенда состоит из отдельных цветов и подписей, а не непрерывного градиента от 1001 до 1005.
5. Сохраните `screenshots/lithology_0_ma.png`.
6. От `ActiveBasin` создайте второй **Threshold**, выберите Cell Data → `lithology_code` и оставьте один код по вашему выбору. Переключите три эпохи и запишите выбранный код и наблюдение в `answers.md`. Если в одной эпохе этого литотипа нет, это допустимый результат.

Сохраните эту ветку в `.pvsm`, отдельный скриншот изолированного литотипа не обязателен.

## 8. Сравните температуру и пористость

1. Разделите Render View на два окна кнопкой **Split Horizontally** или **Split Vertically**.
2. В обоих покажите `ActiveBasin` в современной эпохе.
3. В левом выберите температуру, диапазон **17–170 °C**.
4. В правом — `porosity_fraction`, диапазон **0–0,65**. Подпишите: `Пористость, доля единицы`.
5. Используйте одинаковый ракурс и масштаб. Можно связать камеры через **Tools → Add Camera Link**; если такого пункта нет, выполните привязку через контекстное меню вида или задайте одинаковые параметры камеры.
6. В каждом окне покажите собственную легенду. Сохраните через Save Screenshot весь layout:

```text
screenshots/temperature_and_porosity_0_ma.png
```

Число 0,25 здесь означает долю 0,25, то есть 25 %. Не подписывайте шкалу 0–0,65 как проценты без пересчёта.

## 9. Сделайте анимацию

Для анимации оставьте одно окно с `ActiveBasin`, температурой, общей шкалой **17–170 °C** и неподвижной камерой. Изолинии можно оставить, если они не мешают чтению. Скрытые ветки профиля и литологии удалять не нужно.

Добавьте источник **Annotate Time**. Формат подписи, например:

```text
Elapsed model time: %.1f Ma
```

В версиях с фигурными скобками вместо printf-формата используйте предлагаемый программой шаблон и измените только текстовую часть. Проверьте **видимое число**: в начале должно быть 0, в конце 200. Это прошедшее модельное время, а не возраст до настоящего. Рядом добавьте Text с пояснением `Age (Ma) = 200 - elapsed time`. Статические подписи `Age: 0 Ma` или `Age: 200 Ma` из шага 4 на время анимации скройте.

В Time Manager / Animation View установите **Snap To TimeSteps**, включите все **18 сохранённых состояний**. Сначала проиграйте серию на экране, затем **File → Save Animation**. Разрешение — не менее 1280 × 720, например 2 кадра/с. Убедитесь, что выбран полный диапазон кадров 0–17. Физические интервалы времени неравномерны; наша анимация показывает последовательность состояний, а не достоверную скорость осадконакопления.

Варианты сдачи:

- **18 PNG-кадров** в `screenshots/animation/` — обязательный доступный вариант без видеокодеков;
- **видеофайл**, если экспорт доступен в вашей сборке: загрузите его в доступное преподавателю хранилище и добавьте ссылку в `answers.md` вместо кадров. Проверьте доступ по ссылке.

Не добавляйте большое видео в Git. В репозитории задания видео исключено из отслеживания. Для PNG сохраняйте обычные сжатые изображения, не TIFF/BMP. Проверьте первый, промежуточный и последний кадры: маска и значения меняются, камера и шкала остаются одинаковыми, подпись времени соответствует кадру.

## 10. Сохраните и повторно откройте состояние

**File → Save State**:

```text
homeworks/hw06/basin_visualization.pvsm
```

Закройте текущий сеанс через **File → Disconnect** или перезапустите ParaView. Откройте **File → Load State**. Если программа просит найти исходные файлы, укажите свою папку `homeworks/hw06/data/result_vtk`; при наличии опции поиска подкаталогов включите её. Не редактируйте `.pvsm` вручную ради замены пути.

После загрузки должны работать переключение эпох, маска, изолинии и профиль. На компьютере преподавателя сначала выполняется конвертация (либо распаковывается готовая серия), затем состояние загружается с указанием новой папки VTI. Поэтому одного `.pvsm` без исходных данных было бы недостаточно.

```powershell
git status
git add homeworks/hw06
git diff --cached --stat
git commit -m "Complete homework 6: ParaView basin visualization"
git push
```

В списке подготовленных файлов должны быть ваши PNG/CSV/PVSM/ответы. Сгенерированные папки `result_vtk` и `result_vtk_2` в коммит не входят. Не выполняйте `git add -f` для обхода этого правила.

На индивидуальной сдаче покажите работу фильтров и измените один параметр по просьбе преподавателя: эпоху, положение профиля или уровень изолинии. Будьте готовы объяснить, почему изменение цвета, изменение поля и изменение активной области — разные действия.

Официальные справочные материалы: [открытие временных серий](https://docs.paraview.org/en/latest/UsersGuide/dataIngestion.html), [фильтры](https://docs.paraview.org/en/latest/UsersGuide/filteringData.html), [цветовые карты](https://docs.paraview.org/en/latest/ReferenceManual/colorMapping.html), [сохранение изображений и состояния](https://docs.paraview.org/en/latest/UsersGuide/savingResults.html).
