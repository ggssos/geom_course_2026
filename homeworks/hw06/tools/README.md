# Конвертер результатов для ParaView

**BasinToVTK.exe** — переносимая программа для Windows x64. Установка и отдельный Python не нужны.

1. Откройте EXE.
2. Нажмите **«Выбрать файл для конвертации»**.
3. Выберите HDF5-результат бассейнового солвера, например `../data/result.h5`.
4. Дождитесь завершения. Программа показывает путь к новой папке рядом с исходным файлом.
5. В ParaView откройте из этой папки **`basin.vti.series`**.

Для `result.h5` создаётся папка `result_vtk`. Повторная конвертация создаёт `result_vtk_2` и так далее. Существующие результаты и исходный HDF5 сохраняются.

Программа поддерживает HDF5 формата `basin-thermal-history`, схема 1, `complete = true`, равномерную двумерную сетку и поля `temperature_C`, `reflectance`, `porosity`, `lithology`, `active`. Это конвертер конкретного формата результатов, а не всех существующих HDF5-файлов.

**basin_vtk.zip** — готовая серия для приложенного учебного результата. Это также вариант для macOS/Linux. Распакуйте содержимое архива в `homeworks/hw06/data/result_vtk`; внутри должны оказаться непосредственно `basin_000.vti`, ..., `basin_017.vti`, `basin.vti.series` и `export_summary.json`.

EXE создан преподавателем для этого задания. Он не имеет цифровой подписи издателя. Если на компьютере запуск блокируется политикой организации, используйте готовый архив данных или обратитесь к преподавателю; менять настройки защиты системы не требуется.
