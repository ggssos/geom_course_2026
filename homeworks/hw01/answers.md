wells.csv: данные об одной скважине (координаты x, y, радиус, азимут, давление)
layers.xlsx: данные об одном слое (толщина, пористость)
pumping_test.txt: данные о граничном давлении, давлении в скважине

1. DataFrame представляет собой таблицу с данными, где каждая строка проиндексирована, 
а каждый столбец именован; массив в NumPy это стандартный массив данных, предназначенный
для математических вычислений.
2. В массиве (13, 2) 13 это количество строк, а 2 - количество столбцов.
3. Потому что в NumPy это выполняется автоматически, то есть умножаются все числа
в массиве одновременно.
4. Каждый второй элемент массива, то есть 1-ый, 3-ий, 5-ый и тд. элементы.
5. Содержатся значения True и False, которые показывают, какие строки нужно оставить.
6. Чтобы проверить, что массив правильно сохранился и исходные значения не исказились.
7. Исходные файлы это те, которые читает data_utils.py: wells.csv, layers.xlsx, pumping_test.txt; 
программой создаются следующие файлы, созданные solution.py: wells_clean.csv, table_summary.xlsx,
pressure_matrix.npy, pressure_cube.npz, results.txt.
