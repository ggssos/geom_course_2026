## 2. Вспомните устройство Matplotlib

Создать рисунок и область построения можно одной командой:

```python
fig, ax = plt.subplots(figsize=(8, 5))
```

- `Figure` (`fig`) — весь рисунок, который будет сохранён в файл;
- `Axes` (`ax`) — область с осями координат, внутри которой строится график.

В этом задании используйте объектный интерфейс:

```python
ax.plot(...)
ax.set_xlabel(...)
ax.set_ylabel(...)
fig.savefig(...)
```

Не используйте последовательность команд `plt.plot`, `plt.xlabel`, `plt.ylabel` для оформления готовых рисунков.

Включите:

```python

```
