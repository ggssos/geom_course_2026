# 6.2. Зачем нужен ParaView и как устроена работа

В Matplotlib вы писали команды построения графика. В ParaView многие операции выполняются через интерфейс: открываете сетку с полями, выбираете обработку и настраиваете изображение. Это удобно, когда результатом расчёта является целая область с тысячами или миллионами ячеек и последовательностью временных состояний.

ParaView используется для исследования готовых расчётов: где находится область, как распределена величина, как она изменяется и что видно на выбранном профиле. В нашем задании солвер уже рассчитал температуру, а ParaView помогает рассмотреть результат.

## Геометрия, сетка и поле

**Геометрия** задаёт форму и положение области. **Сетка** разбивает пространство на ячейки и задаёт их узлы. **Поле** присваивает числовые значения точкам или ячейкам: например, температуру.

Для нашего разреза есть прямоугольная сетка и отдельная маска. Значение `active = 1` означает, что в данной ячейке в выбранную эпоху существуют породы, `active = 0` — что ячейка не входит в активную область. Поэтому прямоугольная рамка сетки и форма бассейна могут отличаться.

Окраска меняет способ изображения поля. Она сама по себе не удаляет неактивные ячейки и не изменяет рассчитанные температуры.

## Cell Data и Point Data

**Cell Data** — одно значение на ячейку. В расчёте нашего бассейна температура относится к центру ячейки. Сначала её естественно показывать как цветную прямоугольную ячейку.

**Point Data** — одно значение на узел сетки. Такие данные позволяют строить интерполированные цветовые переходы и изолинии между узлами.

Фильтр **Cell Data to Point Data** вычисляет значения в узлах по соседним ячейкам. Это дополнительная обработка для визуализации. Она не добавляет новых измерений и не делает исходный расчёт точнее. На границе активной области у узла меньше соседних ячеек, поэтому обработку важно выполнять после выделения области.

Код литологии — категория. Литотипы `1001` и `1002` не означают «1001 и 1002 единицы породы». Промежуточный код `1001.5` не является новым литотипом. Литологию показывайте исходными **Cell Data**, отдельным цветом на код, без усреднения кодов в узлах.

## Цепочка обработки Pipeline

Каждый объект в Pipeline Browser получает данные и выдаёт результат следующему объекту. Один источник можно использовать в нескольких ветках.

```text
Временная серия VTI
└── Threshold: active = 1
    ├── отображение температуры по ячейкам
    ├── Threshold: выбранный код литологии
    └── Cell Data to Point Data: только temperature_C
        ├── Contour: температурные изолинии
        └── Plot Over Line: температурный профиль
```

Новый фильтр применяется к **выбранному** объекту. Если выбрать исходную серию вместо результата Threshold, ветка снова будет работать с полной прямоугольной сеткой.

Чтобы добавить фильтр, выделите вход в Pipeline Browser, нажмите **Ctrl+Space**, введите имя фильтра и нажмите Enter. Затем задайте параметры и нажмите **Apply**. Значок глаза управляет только видимостью объекта; невидимый источник продолжает передавать данные фильтру.

## Четыре действия, которые легко перепутать

| Действие | Что меняется |
| --- | --- |
| Выбрать поле в Coloring | Величина, по которой раскрашивается объект |
| Выбрать Surface / Surface With Edges | Способ изображения той же сетки |
| Применить Threshold | Набор ячеек, передаваемых дальше |
| Передвинуть камеру | Положение наблюдателя; координаты и значения не меняются |

Фильтр **Contour** строит линию постоянного значения на двумерном разрезе. Фильтр **Plot Over Line** отбирает значения вдоль заданного отрезка и создаёт график. **Clip** оставляет часть области по геометрическому условию; **Slice** пересекает её плоскостью. Последние два особенно полезны для объёмных данных; у нас основной объект — плоский разрез.

## Цветовая шкала — числовое соответствие

Если в первом кадре красный означает 50 °C, а во втором — 170 °C, картинки нельзя напрямую сравнивать. Поэтому для анимации температуры установите один диапазон **17–170 °C** и отключите автоматическое изменение диапазона.

В окне редактирования цветовой карты используйте **Rescale to Custom Range**. Если есть настройка **Automatic Rescale Range Mode**, выберите **Never**. В разных версиях она может находиться в дополнительных свойствах. Проверьте результат: при смене эпох нижнее и верхнее числа на легенде должны оставаться теми же.

Для температуры и пористости используйте последовательную цветовую карту. Для кода литологии — категориальную: отдельные цвета и подписи кодов. Для разности со знаком подходила бы расходящаяся шкала с центром в нуле, как для карты ошибок.

## Время в наших данных

Геологический возраст отсчитывается до настоящего: 200 Ma — древнее, 0 Ma — современность. Ma здесь означает миллионы лет.

Для возрастающей шкалы ParaView конвертер использует:

```text
elapsed_time_ma = 200 - age_ma
```

| Геологический возраст age_ma | Время ParaView elapsed_time_ma |
| ---: | ---: |
| 200 | 0 |
| 75 | 125 |
| 15 | 185 |
| 0 | 200 |

Моменты сохранены неравномерно. Анимация в режиме **Snap To TimeSteps** последовательно показывает сохранённые кадры. При одинаковой длительности каждого кадра она не передаёт длительности геологических интервалов в правильном масштабе. Изменения между сохранёнными эпохами в этих данных не известны.

## Мини-упражнение на тестовой сетке

Продолжите работу с `installation_test.vti` из 6.1.

1. Выберите исходный файл в Pipeline Browser.
2. Добавьте **Threshold** через Ctrl+Space.
3. Выберите **Cell Data → active**, метод **Between**, нижний и верхний пороги **1**. В некоторых версиях подпись метода или полей немного отличается; смысл условия — `1 ≤ active ≤ 1`.
4. Нажмите Apply, скройте исходный файл значком глаза и покажите результат фильтра.
5. Выберите `temperature_C` и Surface With Edges.

Теперь видны **пять ячеек**. Шестая осталась в исходном файле, но не прошла условие Threshold. Чтобы увидеть числа, разделите окно кнопкой Split и в новом представлении выберите **SpreadSheet View**. Для результата фильтра включите отображение Cell Data.

## Сохранение состояния

**File → Save State** записывает `.pvsm`: источники, цепочки фильтров и настройки представлений. Сам массив температур в этот файл не переносится. Если переместить исходные VTI, при загрузке состояния нужно будет указать их новое расположение.

Изображение сохраняется через **File → Save Screenshot**, а данные выбранного фильтра — через **File → Save Data**. Это три разных результата: настройки, картинка и числовые значения.

Источники: [модель данных ParaView](https://docs.paraview.org/en/latest/UsersGuide/understandingData.html), [работа с фильтрами](https://docs.paraview.org/en/latest/UsersGuide/filteringData.html), [анимация](https://docs.paraview.org/en/latest/UsersGuide/animation.html), [сохранение результатов](https://docs.paraview.org/en/latest/UsersGuide/savingResults.html).
